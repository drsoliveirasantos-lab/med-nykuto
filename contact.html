Ayuda y seguimiento

Centro de ayuda

Cuéntanos si necesitas ayuda con una materia, tarea, archivo, acceso de delegado o problema técnico. Al enviar recibirás una referencia para poder seguir tu solicitud.

Solicitud

¿En qué podemos ayudarte?

El nombre y el medio de respuesta son opcionales para consultas generales y obligatorios para pedir acceso de delegado. El ticket no se presenta como registrado hasta que el servidor lo confirma.

Antes de enviar

Cómo recibir una ayuda útil

  • Indica la materia y la página relacionada cuando sea posible.
  • Para un problema visual, indica tu dispositivo y navegador.
  • No compartas contraseñas, datos bancarios ni información que identifique a un paciente.
Borrador local

Si el navegador permite el almacenamiento local, intentamos conservar aquí tu texto y el identificador de la solicitud para que puedas reintentarlo.
